`expert-fee-claim` 스킬을 로드하고 P0→P7 파이프라인을 실행한다.

입력: $ARGUMENTS

진행 방식:
1. `scripts/doctor.py` 로 환경을 확인하고, 부족한 것은 먼저 보고한다.
2. `claims/<YYMMDD>-<expert_id>/` 작업 디렉토리를 만들고 인테이크를 돌린다.
3. 녹취·자료를 읽어 `claim.json` 을 사전 예측으로 채운다(confirmed/inferred/unknown).
4. **인터뷰 부트스트랩 턴을 띄우고 사람 응답을 기다린다.** 여기서 반드시 멈춘다.
5. 응답 반영 후 보고서 2종 → 도식 → 양식 2종 → 번들 점검 순으로 진행한다.

주민등록번호·계좌번호는 대화에 노출하지 않는다. 전문가 프로필 파일에서 스크립트가 직접 읽는다.
