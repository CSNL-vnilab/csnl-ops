# 제출 전 최종 점검

`scripts/bundle.py` 가 기계적으로 검사할 수 있는 항목은 자동 검사하고, 나머지는 사람에게 표로 보고한다.

## 자동 검사 (스크립트)

| # | 항목 | 실패 조건 |
|---|---|---|
| 0 | 최종 산출물 3종 | 사용내역서 xlsx · 일회성경비 xlsx · 자문내용정리 pdf 중 하나라도 없음 |
| 1 | 사용내역서 필수 셀 | 과제번호·과제명·활용일자·시간·금액·인적사항 중 빈칸 |
| 2 | 일회성경비 `END` 행 | 마지막 데이터 행 다음에 `END` 없음 |
| 3 | 계좌번호 형식 | 하이픈·공백 잔존 |
| 4 | 은행명/국적/상세소득구분 | 유효값 목록에 없음 |
| 5 | 금액 일치 | 사용내역서 총액 ≠ 일회성경비 지급액 |
| 6 | 활용일자 ↔ 보고서 일시 | 두 문서의 날짜 불일치 |
| 7 | 활용시간 ↔ 보고서 | 사용내역서 시간 ≠ 보고서 "총 N시간" |
| 8 | 첨부 파일 존재 | 첨부목록에 적힌 파일이 `out/` 에 없음 |
| 9 | 양식 내 이전 건 잔여정보 | 셀 문자열에 서로 다른 주민번호 2개 이상, 또는 청구 대상이 아닌 `mailto:` 주소 |
| 10 | 개인정보 유출 | `out/` 의 docx/pdf/md 에 주민번호 패턴 존재 → **즉시 실패** |
| 11 | 미확인 마커 | 본문에 `【확인 필요` 문자열 잔존 |

## 사람이 해야 할 잔여 작업 (항상 보고)

- [ ] 사용내역서 **개인정보 수집·이용 동의 3항목 체크** (ActiveX 컨트롤 — 스크립트 조작 불가)
- [ ] 전문가 **서명**
- [ ] 연구책임자 **날인**
- [ ] 회의 사진 첨부 (없으면 첨부목록에서 제거)
- [ ] 연구비 관리 시스템 업로드 / 담당자 메일 발송

## 보고 형식

```
■ 자동 검사 12/12 통과
■ 잔여 작업 5건 (위 목록)
■ 산출물
   out/자문내용정리_260403.pdf
   out/<전문가명>_전문가활용비_260403.xlsx
   out/<전문가명>_일회성경비.xlsx
```

실패 항목이 있으면 **무엇이 왜 실패했고 어떻게 고치는지**를 함께 쓴다. 통과율만 보고하지 않는다.
