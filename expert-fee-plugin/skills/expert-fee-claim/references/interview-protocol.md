# 확인 인터뷰 프로토콜

`interview` 스킬의 하위 적용. **한 턴 한 질문**(부트스트랩 턴만 최대 3문항), **사전 예측 우선**, **거울 인용**.

## 턴 0 — 부트스트랩 (최대 3문항)

녹취·자료에서 뽑은 예측을 표로 보여주고 정정만 받는다.

```
녹음과 회의자료에서 이렇게 파악했습니다. 틀린 곳만 알려주세요.

| 항목 | 파악한 값 | 근거 |
|---|---|---|
| 참석자 | 박준오 연구원, 신재솔 연구원 | 기본값 |
| 일자 | 2026-04-03 | 녹음 파일 생성일 |
| 형태/장소 | 대면 / 서울대 220동 650호 | "650호에서" (녹취 03:12) |
| 활용시간 | 4시간 | 녹음 3시간 47분 → 반올림 (추정) |

1) 위 표에서 고칠 것이 있나요?
2) 이번 자문의 핵심 안건을 한 줄로 말한다면?
3) 첨부할 회의자료·사진이 따로 있나요?
```

## 턴 1 이후 — 한 번에 하나

`unknown` 우선순위 순으로 딱 하나만 묻는다. 답을 받으면 **인용 + 한 줄 요약 + 다음 질문**.

```
"4시간이 아니라 3시간"
→ 활용시간 3시간으로 수정했습니다. 사용내역서 '시간/회당/장' 칸에 3이 들어갑니다.

다음: 이번 건 지급액은 지난번과 같은 400,000원인가요?
```

## 필드별 기본값 · 질문 문구

| 필드 | 기본값 | 질문 |
|---|---|---|
| 참석자 | 박준오 연구원, 신재솔 연구원 | "참석자는 박준오·신재솔 두 분 맞나요? 추가된 분 있나요?" |
| 자문위원 | 신재솔 (위데이터랩 대표 / AI 솔루션 전문가) | "지급 대상 전문가는 신재솔 대표님이 맞나요?" |
| 일자 | 녹음 파일 mtime | "자문 일자는 {날짜}로 기재하면 될까요?" |
| 회차 | 1차 | "이번이 몇 차 자문인가요? (지난 건: {최근 청구 이력})" |
| 활용시간 | 녹음 길이 반올림 | "활용시간은 {N}시간으로 기재할까요? 준비·정리 시간 포함해서요." |
| 형태 | 녹취에 Zoom 언급 있으면 비대면 | "대면이었나요, Zoom이었나요?" |
| 장소 | 대면 → 서울대 220동 650호 / 비대면 → 온라인 Zoom 화상회의 | 형태 확정 후에만 |
| 금액 | 400,000원 | "지급액은 400,000원으로 진행할까요?" |
| 소득구분 | 기타소득 / 그 외 필요경비 없는 기타소득 | 기본값 사용, 변경 시에만 확인 |
| 출장경비 | 없음(0) | 대면 + 외부인일 때만 "교통비 청구할 게 있나요?" |
| 제목 | 자동 초안 | "제목을 '{초안}'으로 하려는데 괜찮나요?" |
| 첨부 | 회의자료 예시 + 회의 사진 | "회의 사진 있나요? 없으면 첨부목록에서 뺄게요." |

## 하지 말 것

- 주민번호·계좌번호를 대화창에서 묻지 않는다. **프로필 파일에 직접 넣도록 안내**한다.
- 이미 프로필/과제 파일에 있는 값(과제번호, 책임자, 연구기간)을 다시 묻지 않는다.
- 한 턴에 5개 질문을 쏟아붓지 않는다. 응답률이 떨어지고 답이 뭉개진다.
- 답을 못 받은 채로 문서를 확정하지 않는다. 미확인 필드는 `【확인 필요: …】` 로 본문에 남긴다.

## 종료

필수 필드 `unknown = 0` 이면 확정 요약을 한 번 보여주고 P4로 넘어간다.
