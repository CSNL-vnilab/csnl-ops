# 산학협력단 양식 필드 매핑

대상 양식 2종. 둘 다 **공식 빈 양식**을 `~/.claude/snu-expert-fee/config/forms/` 에 두고 복사본에 기입한다.
양식 원본은 절대 수정하지 않는다.

---

## A. 전문가활용비 사용내역서 (`전문가활용비_사용내역서.xlsx`)

시트 1장. 라벨 앵커 방식으로 채운다 — 라벨 셀을 찾고, 지정된 열 오프셋(dx)만큼 오른쪽 셀(병합 시 병합범위 좌상단)에 쓴다.

| 라벨 (앵커) | dx | claim.json 경로 | 예시 값 | 비고 |
|---|---|---|---|---|
| `SRnD 과제번호` | +1 | `project.srnd_no` | 339-20250011 | |
| `연구책임자` (1번째) | +2 | `project.pi` | 이 상 훈 | 양식은 성명 사이 공백 표기 |
| `연구과제명` | +1 | `project.title` | | 긴 문장, 줄바꿈 허용 |
| `지원기관` | +2 | `project.funder` | 한국연구재단 | |
| `연구기간` | +1 | `project.period` | 2025.05.01~2026.04.30 | |
| `지원사업` | +2 | `project.program` | 중견연구자지원사업 | |
| `구분` (1번째, A열) | +1 | `payment.kind` | 자문료 | 자문료/강사료/원고료 등 |
| `대면/비대면` | +2 | `meeting.mode` | 대면 \| 비대면 | |
| `구분` (2번째, I열) | +2 | `expert.residency` | 내국인 \| 외국인 | |
| `활용일자` | +1 | `meeting.date_range` | 2026.04.03~2026.04.03 | 단일일도 `A~A` 형식 |
| `활용시간` | +2 | `meeting.hours_note` | 첨부서류참조 | 회차별 상이 시 이 문구 사용 |
| `시간/회당/장` | +1 | `meeting.total_hours` | 4 | 숫자만. 단위 셀은 이미 "시간" |
| `직급(직위)` | +2 | `expert.rank` | 연구자 급 | 산학협력단 단가표 등급 |
| `장소` | +2 | `meeting.place` | 서울대학교 220동 650호 | 비대면이면 "온라인 Zoom" |
| `제목` | +1 | `report.title` | 연구실 맞춤형 데이터베이스 및 인공지능 설계 자문 | |
| `목적\n(활용내용)` | +1 | `report.purpose_short` | | 2~3줄 요약 |

### 인적사항 블록
헤더 행에서 `이름 / 소속 / 주민등록번호 / 이메일주소 / 은행명 / 계좌번호 / 예금주` 셀의 **열 위치**를 읽고, **헤더행 + 1** 행에 값을 쓴다.

| 헤더 | claim/profile 경로 | 마스킹 |
|---|---|---|
| 이름 | `expert.name` | — |
| 소속 | `expert.affiliation` | — |
| 주민등록번호 | `expert.rrn` (프로필 파일에서만) | 보고 시 `앞6-1******` |
| 이메일주소 | `expert.email` | — |
| 은행명 | `expert.bank` | — |
| 계좌번호 | `expert.account` | 보고 시 앞4·뒤2만 |
| 예금주 | `expert.account_holder` | — |

### 금액 블록
`활용비` / `출장경비(항공료·교통료·체재비·숙박비)` / `총액` 헤더 셀을 찾고 **헤더행 + 2** 행에 쓴다(2단 헤더).

- `활용비` ← `payment.amount` (세전)
- 출장경비 4칸 ← `payment.travel.{air,transport,per_diem,lodging}` (없으면 0 또는 공란)
- `총액` ← 활용비 + 출장경비 합

### 하단
- `상기와 같이 … 청구합니다.` 문장 행 **+1** 행 A열 ← `claim.request_date` (YYYY-MM-DD)
- `(인)` 셀이 있는 행 → 그 열 **-1** ← `project.pi`
- `* 첨부서류 목록` 행 **+1** 부터 ← `bundle.attachments[]` 각 줄

### 개인정보 동의 체크박스
양식의 동의 체크박스는 ActiveX 컨트롤이라 openpyxl로 조작할 수 없다. **스크립트는 건드리지 않고**, 사용자에게 "엑셀에서 동의 3항목 체크 + 서명 필요"를 잔여 작업으로 보고한다.

## B. 일회성경비 지급 업로드 양식 (`일회성경비.xlsx`)

`Sheet1` — 2행 헤더, **3행부터 데이터**, 마지막 데이터 행 바로 아래에 `END` 필수(지우면 업로드 에러).

| 열 | 헤더 | 값 |
|---|---|---|
| A | 순번 | 1부터 |
| B | 성명 | `expert.name` |
| C | 소속부서 | `expert.affiliation` |
| D | 주민등록번호 앞자리 | 6자리 |
| E | 뒷자리 | 7자리 |
| F | 외국인 여부 | `N` / `Y` |
| G | 여권번호 | 외국인만 |
| H | 국적 | `대한민국` — 2번째 시트 유효값 목록과 정확히 일치해야 함 |
| I | 소득구분 | `기타소득` |
| J | 상세소득구분 | `그 외 필요경비 없는 기타소득` (세율 22%) |
| K | 지급액 | 세전 금액 |
| L | 계좌번호 | **하이픈 없이 숫자만** |
| M | 은행명 | `국민은행` 등 — 유효값 목록과 정확히 일치 |
| N | 예금주 | |
| O~R | 항공료/교통료/체재비/숙박비 | 자문료·강사료일 때만, 없으면 0 |

### 유효성 규칙 (스크립트가 강제)
1. `국적`·`은행명`·`상세소득구분`은 2번째 시트 `업로드 양식 유효성 검사 기준`의 목록에 있어야 한다. 없으면 **에러로 중단**하고 후보를 제시한다.
2. 계좌번호에 하이픈/공백이 있으면 제거한다.
3. 예금주는 특수문자 자동변환(`(주)`→`㈜`) 위험이 있으므로 원문 그대로 문자열로 쓴다.
4. 마지막 행 다음에 `END`가 없으면 추가한다.

### 세액 참고 (양식 기입값 아님)
`그 외 필요경비 없는 기타소득` 세율 22% → 실지급액 = 지급액 × 0.78.
예: 400,000원 → 원천징수 88,000원, 실수령 312,000원. 보고용으로만 계산해 알려준다.

## C. 지난 청구 건을 양식으로 재사용할 때

공식 빈 양식이 없어 **지난 제출본을 복사해 쓰는 경우**, 셀을 비우는 것만으로는 부족하다.

| 남는 곳 | 내용 | 처리 |
|---|---|---|
| `xl/sharedStrings.xml` | 이전 전문가 이름·소속·주민번호 문자열 | `xlsx_edit.Workbook.save()` 가 참조되지 않는 항목을 비운다 |
| `xl/worksheets/_rels/sheetN.xml.rels` | 이메일 `mailto:` 하이퍼링크 | 셀을 쓸 때 하이퍼링크와 관계 항목을 함께 제거한다 |
| 수식 캐시 `<v>` | 이전 총액 | `fullCalcOnLoad` 로 열 때 재계산 |
| `docProps/core.xml` | 작성자 이름 | 필요하면 수동 확인 |

`bundle.py` 의 **"양식 내 이전 건 잔여정보 없음"** 검사가 이 상태를 잡는다:
셀 문자열에서 서로 다른 주민번호가 2개 이상 발견되거나, 청구 대상이 아닌 `mailto:` 주소가
남아 있으면 실패한다.
