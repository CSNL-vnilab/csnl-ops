# DM Drafts

NAS-grounded uncertainty Q drafts awaiting operator (user) pre-check before send.

Each `<INIT>_<YYYY-MM-DD>.md` contains:
- Routing block (recipient, channel, send mode, kind tag)
- Context (why this draft, what NAS evidence)
- Draft body (Korean academic tone, includes (P1)..(P5) opt-out footer)
- Lint pre-check vs slack_outbound._enforce_or_raise rules
- Risks/uncertainties for user to verify before send

Drafts are NOT auto-sent. Per `feedback_first_run_external` memory rule:
operator (interactive Claude Code session) drafts → user reviews → user OKs send.
